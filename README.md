
# Some Setup
To run this this on localhost:7775 I port mapped 7775 to 3000, meaning my local Windows host port is forwarded to port 3000 inside the container. 
We can now access my React Application using http://localhost:7775.

# To Run Application:
- git clone the repository onto local 
- run docker compose up --build
- go to http://localhost:7775

** Make sure docker desktop is running by using docker desktop start
